Install now to start building your AI Social Credit Score

Clone the Claude Code plugin and start a session with scoring enabled. Publishing begins automatically for new installations.

Requires Claude Code, a Claude subscription, Git, and Python 3. Scoring uses your existing Claude login and plan allowance.

ONE-LINE LOCAL SETUP01 / 01
git clone https://github.com/michaelrbock/ai-social-credit-score.git && cd ai-social-credit-score && AI_SOCIAL_CREDIT_SCORE_SCORING_ENABLED=1 claude --plugin-dir .

This loads the plugin for one Claude Code session. It automatically uploads your pseudonymous username, aggregate score, scored-prompt count, score date, and rubric version after a random 1–10 new scores. Prompts and rationales stay local. Use /ai-social-credit-score:unpublish to remove your record.
